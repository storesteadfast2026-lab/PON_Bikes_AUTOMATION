# 12 — Automatic Mapping

The import analyser proposes worksheet, header row, first data row and relevant field columns. Detection combines header signals, data patterns, saved customer/workbook mapping history and available business validation.

Container detection recognises container-style values even where the header is not explicitly named Container. High-confidence mappings can be reused; uncertain fields remain for review rather than being invented.

Confirmed mapping profiles can be reused for the same Customer/file structure. Multi-container preview reports the detected container subsets before confirmation.
