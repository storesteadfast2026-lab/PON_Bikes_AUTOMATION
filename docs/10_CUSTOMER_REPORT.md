# 10 — Customer Report

The customer receiving report is based on the confirmed client manifest, confirmed First Scan and active Product Master/product classification data.

The report retains the established columns and variance behaviour. NEW products are identified using the current classification state for the container.

Customer Report remains independent of the stage-selector UI change and continues to use the existing backend/export implementation.

## Download filename

The final Customer Report download name is:

```text
<CONTAINER> Advised.xls
```

Example:

```text
ONEU1569467 Advised.xls
```

This changes only the HTTP download filename. The stored audit copy, workbook content, workbook-generation logic and current content type remain unchanged.

Customer Report shows **Generated** from the existing GeneratedExport timestamp. **Uploaded** is shown separately as not applicable because the report is generated by PON.

## PBP → PON visual marker (0930.1602)

Rows classified **PBP → PON** are not marked `New` in the Customer Report. Their quantities, received values, variance and comment logic remain unchanged. The complete report row is filled orange (`#F4B183`) only as an operator/client visual marker for a PBP-to-PON migration.
