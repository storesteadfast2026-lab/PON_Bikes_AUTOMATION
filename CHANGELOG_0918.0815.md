# PON Bike Automation 0918.0815

## UPStockSerial.csv ordering aligned with legacy Excel

- `UPStockSerial.csv` is now written in ascending numeric `Movement` order.
- The Movement -> serial_no -> Loc assignment created during Stage 2 reconciliation is not changed; only the final row order is changed.
- The historical three-column layout remains `Movement,serial_no,Loc`.
- Movement values keep the existing right-aligned 10-character representation.
- The historical 500 data-row output shape is preserved.
- No database migration is required for this release.

## Regression coverage

Added a Stage 2 regression test with movements supplied out of order. The generated output must be ascending by Movement while retaining the original serial_no and location paired with each Movement.

## Real-file validation

The 85-row UPStockSerial generated by the application in the FDCU0321443 test was sorted using the new rule and compared with the legacy Excel-generated `UPStockSerial2.csv`. The result was byte-for-byte identical, including the 415 blank padded rows.
